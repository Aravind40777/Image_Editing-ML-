# Image Processing App using Streamlit(Basic)

This is a simple web application built using Streamlit and OpenCV that allows users to display and resize an image interactively.

## Features

* Display an image using OpenCV
* Resize image dynamically using sliders
* Simple and interactive UI
* Beginner-friendly project

## Technologies Used

* Python
* Streamlit
* OpenCV

## Project Structure

project-folder/
│── app.py
│── SRH-logo.jpg
│── README.md

## Usage

* The app displays an image (SRH-logo.jpg)
* Use sliders to adjust height and width
* The resized image will be shown instantly


## Output

* Displays original image
* Displays resized image based on user input

## Note

* Make sure the image file SRH-logo.jpg is present in the project folder
* If the image is not found, the app may not display anything


## How to Run the Project

### 1. Clone the repository

```
git clone https://github.com/your-username/Image_Editing-ML-.git
cd Image_Editing-ML-
```

### 2. Create virtual environment (optional but recommended)

```
python -m venv env
env\Scripts\activate
```

### 3. Install dependencies

```
pip install streamlit opencv-python
```

### 4. Run the app

```
streamlit run app.py
```
